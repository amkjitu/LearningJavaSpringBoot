## Spring JPA REST API with database MySQL
This is a simple Spring Boot application that demonstrates how to create a REST API with a MySQL database using JPA.

By using CrudRepository, we can easily perform CRUD operations on the database without writing any SQL queries. this magic is done by Spring Data JPA, which provides a powerful abstraction layer over the database.

* @Autowired: This annotation is used to automatically implement the dependency injection of the repository into the resource/service class. It allows Spring to resolve and inject the collaborating beans into our bean.
